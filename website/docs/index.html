01 / SUPPORTED TELEMETRY FORMATS.SRT EXIF INJECTION

Automatic SRT Cue Parsing

posEye parses DJI and Autel subtitle telemetry streams, aligns each extracted frame via nearest-neighbor search (≤ 1.5s tolerance), and writes WGS 84 DMS coordinates plus AMSL altitude into JPEG EXIF headers. Pre-flight frames outside telemetry bounds are rejected cleanly.
