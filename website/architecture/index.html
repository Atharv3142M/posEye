ORIGIN CENTERED (0, 0, 0)

Zero vertex shimmer on large UTM models.

Raw UTM coordinates lie hundreds of thousands of meters from world zero, exhausting 32-bit WebGL float precision. posEye translates every reconstructed mesh bounding box cleanly to (0, 0, 0) while keeping the exact offset vector to show true georeferenced coordinates in the HUD.
