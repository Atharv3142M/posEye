DESKTOP APPLICATION · 04

An offline workstation you control.

posEye is an active desktop system for Windows, designed for local processing without subscription fees, cloud queues, or external data transfer.

Drag & Drop Ingestion

Simply drag your drone flight video file (.mp4, .mov) onto posEye. The system automatically searches for corresponding subtitle telemetry files (.srt), probes the video parameters using bundled static FFmpeg, and calculates estimated frame count and duration.

✓ Automatic companion .SRT file discovery ✓ Static bundled FFmpeg binary (zero PATH setup) ✓ Real-time resolution, duration & FPS inspection
$ ffprobe -v error -show_entries stream=width,height,r_frame_rate,duration test_flight.mp4
[STREAM]
width=3840
height=2160
r_frame_rate=30/1
duration=184.200000
[/STREAM]
[posEye] Ingestion valid: 4K UHD @ 30 FPS, SRT telemetry verified.

11-Stage Real-Time HUD

Never wonder what the photogrammetry engine is doing. The posEye UI connects via WebSocket to the FastAPI orchestrator, streaming stage percentage, active subroutines, and time remaining across all 11 stages.

✓ WebSocket real-time event telemetry ✓ Distinct progress for extraction, SfM, MVS & meshing ✓ Resilient job persistence stored in job.json

HARDWARE SPECIFICATIONS

System requirements.

OPERATING SYSTEM

Windows 10 / 11

64-bit architecture with WSL2 (Windows Subsystem for Linux) and Docker Desktop installed.

MEMORY & STORAGE

16 GB+ RAM / SSD

Photogrammetry is memory-intensive. 32 GB RAM is recommended for 4K video reconstructions.

GRAPHICS

OpenGL 3.3+ GPU

Dedicated NVIDIA or AMD GPU for hardware-accelerated 3D viewport rendering and future CUDA SfM.
