SYSTEM TOPOLOGY

Four distinct component layers.

LAYER 1 · EXTRACTION

apps/pipeline

Python-based frame extraction, OpenCV Laplacian variance sharpness detection, dHash perceptual deduplication, SRT subtitle telemetry parser, and piexif geotagging.

Python 3.10+ · OpenCV · FFmpeg
LAYER 2 · ORCHESTRATION

apps/orchestrator

FastAPI service on localhost:8765. Manages the lifecycle of stages 1→2→3, handles WebSocket status progress streaming, and interacts with Docker.

FastAPI · uvicorn · httpx
LAYER 3 · RECONSTRUCTION

NodeODM Engine

Isolated Docker container running OpenDroneMap on port 3000. Computes camera poses, sparse tie points, dense multi-view stereo, and surface texturing.

Docker · OpenSfM · OpenMVS
LAYER 4 · DESKTOP UI

apps/desktop

Electron desktop shell bundling React 18, Three.js GLTFLoader viewer, OrbitControls, metric point-to-point measurement, and live circular log streaming.

Electron 32 · React 18 · Three.js
