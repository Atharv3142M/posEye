Windows 10 / 11 Desktop Package

posEye v0.1.9.

Distributed as an NSIS desktop installer containing the Electron shell, compiled FastAPI orchestrator, static FFmpeg binary, and Three.js 3D viewer.

OPTION 01 / PACKAGED INSTALLER

Windows NSIS Release

Install directly on Windows 10 or 11 (x64) without manual Python or FFmpeg setup. Docker Desktop is used locally to run the posEye Construction Engine container.

OPTION 02 / BUILD FROM SOURCE

Reproduce Locally

Requires Python 3.10+, Node.js, and PowerShell on Windows. Run from the repository root:

.\scripts\setup.ps1
.\scripts\fetch-ffmpeg.ps1
.\scripts\build-orchestrator.ps1
cd apps\desktop
npm install
npm run build
npm run dist
