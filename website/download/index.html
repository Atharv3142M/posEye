OPTION 02 / BUILD FROM SOURCE

Reproduce Locally

Requires Python 3.10+, Node.js, and PowerShell on Windows. Run these commands from the repository root:

.\scripts\setup.ps1
.\scripts\fetch-ffmpeg.ps1
.\scripts\build-orchestrator.ps1
cd apps\desktop
npm install
npm run build
npm run dist

System Pre-Requisites

  • Windows 10 / 11 64-bit (Build 19041+)
  • Docker Desktop for Windows (WSL 2 backend enabled)
  • NVIDIA GPU with 4GB+ VRAM recommended for CUDA
  • 16GB RAM and 20GB free disk space for reconstruction jobs
