02 / WORKSTATION PREREQUISITES MINIMUM VS RECOMMENDED
COMPUTE & MEMORY

6+ Core CPU · 16–64 GB RAM

Minimum 6-core x86_64 CPU and 16 GB RAM. 16+ cores and 32–64 GB RAM recommended for dense multi-view meshing.

GPU ACCELERATION

WebGL 2.0 / NVIDIA CUDA

NVIDIA RTX 3060+ with CUDA Container Toolkit accelerates feature extraction; gracefully falls back to CPU execution when absent.

VIRTUALIZATION & DISK

Windows 10/11 + WSL2 + NVMe

Requires Windows 10 (19041+) or Windows 11 x64 with hardware virtualization (VT-x / AMD-V) enabled and 25–100+ GB SSD space.
