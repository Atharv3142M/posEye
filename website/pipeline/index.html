Every job transitions through an immutable state graph managed by the posEye Spatial Orchestrator and executed locally by the posEye Construction Engine.

01 / validating STAGE 01–02 // FFMPEG INGEST
STATE: validatingPHASE 01

Media & Telemetry Probe

Verifies container integrity, codec streams, resolution, FPS, duration, and SRT bounds before allocating job workspace.

STATE: extractingPHASE 02

Static FFmpeg Frame Extraction

Managed subprocess extraction samples candidate frames using the bundled static FFmpeg binary with clean cancellation teardown.

STATE: filteringPHASE 03

Laplacian Blur & dHash Deduplication

Discards motion-blurred frames via OpenCV Laplacian variance and removes redundant hovers via 64-bit perceptual hashing (~70–80% overlap).

STATE: geotaggingPHASE 04

WGS 84 EXIF & Timestamp Provenance

Matches frames to SRT cues within 1.5s drift, writes EPSG:4326 DMS coordinates, preserves AMSL altitude (`GPSAltitudeRef`), and stamps true capture dates.

STATE: maskingPHASE 05

Dynamic Obstruction Masking

Optional YOLOv8n segmentation identifies transient vehicles and personnel, writing masks so moving objects never ghost static geometry.

STATE: dispatchingPHASE 06

Loopback Engine Dispatch

Packages geotagged frames and masks into an authenticated local payload dispatched strictly over 127.0.0.1.

STATE: reconstructingPHASE 07

posEye Construction Engine

Executes sparse bundle adjustment, dense point field synthesis, Poisson surface meshing, texture baking, and orthomosaics (CUDA GPU or CPU fallback).

STATE: postprocessingPHASE 08

Zip-Slip Hardened Extraction

Unpacks output archives through canonical path confinement, blocking traversal, symlinks, and decompression bombs.

STATE: convertingPHASE 09

Draco GLB & Origin Centering

Converts surface meshes to Draco-compressed binary glTF, centers bounding boxes to (0, 0, 0), and verifies vertex buffers.

STATE: readyPHASE 10

Immutable Completion & Export

Persists project state to job.json and streams the verified model into the 3D viewport alongside .LAZ, .TIF, and .PDF exports.

STATE: cancelledPHASE 11

Graceful Subprocess Cancellation

Operators can cancel active runs safely at any point; subprocess trees terminate cleanly and partial scratch files are purged.
