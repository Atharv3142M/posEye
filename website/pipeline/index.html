STAGE 01 / PHASE 1 : INGEST

Video Probing & Validation

FFprobe inspects container integrity, video codec (H.264 / H.265 / ProRes), frame resolution, FPS, and pixel aspect ratio. If streams are corrupt or missing video tracks, the pipeline halts with actionable diagnostic guidance before consuming system resources.

FFprobe Codec Check Container Validation Fast Fail
STAGE 02 / PHASE 1 : INGEST

FFmpeg Frame Extraction

Bundled static FFmpeg (101MB standalone binary) samples candidate frames along a configurable cadence (typically 1 to 2 frames per second). Frame filenames strictly encode their zero-indexed sequential order and millisecond timestamps to allow precise alignment with SRT telemetry.

Static FFmpeg Keyframe Extraction Millisecond Timestamps
STAGE 03 / PHASE 1 : INGEST

Laplacian Blur Filtering

OpenCV calculates the variance of the Laplacian second derivative across each extracted grayscale still. Images suffering from UAV motion blur, gimbal vibration, or lens defocus fall below the threshold (default 100.0) and are discarded to protect reconstruction sharpness.

OpenCV Laplacian Variance Focus Detection Motion Blur Drop
STAGE 04 / PHASE 1 : INGEST

dHash Deduplication

Perceptual difference hashing (dHash) computes 64-bit structural gradients. Stills captured while the drone was hovering or stationary produce near-zero Hamming distances (≤ 10) and are pruned, reducing reconstruction times by up to 40% while preserving baseline camera overlap.

dHash 64-bit Hamming Distance Hover Pruning 40% Speedup
STAGE 05 / PHASE 1 : INGEST

SRT Telemetry Parsing

The parser ingests subtitle streams in DJI parenthesized format [latitude: 27.1751] [longitude: 78.0421] [altitude: 171.2], CSV logs, or key-value subtitle cues. It normalizes GPS coordinates into WGS 84 decimal degrees and AMSL heights with sub-millisecond precision.

DJI SRT WGS 84 AMSL Altitude Sub-second Sync
STAGE 06 / PHASE 1 : INGEST

EXIF GPS Injection

piexif embeds WGS 84 (EPSG:4326) rational coordinates, GPS altitude references, and UTC timestamps into the surviving JPEG headers. Frames matching telemetry within a 1.5-second nearest-neighbor tolerance are stamped, enabling metric scale photogrammetry.

piexif EXIF 2.31 EPSG:4326 Metric Grounding
STAGE 07 / PHASE 1 : INGEST

Optional Dynamic Masking

YOLOv8n instance segmentation detects moving transient objects (cars, pedestrians, boats). When enabled in project settings, binary mask PNGs are generated so the reconstruction algorithm ignores fleeting objects that would otherwise cause reconstruction artifacts.

YOLOv8n Dynamic Masking Artifact Prevention Local PyTorch
STAGE 08 / PHASE 2 : RECONSTRUCTION

Archive Staging & Engine Dispatch

The curated geotagged JPEG stills, EXIF manifests, and optional mask masks are bundled in memory and transferred over localhost HTTP to the local posEye Construction Engine running via Docker.

Zip Packaging Localhost Dispatch Zero Cloud Upload
STAGE 09 / PHASE 2 : RECONSTRUCTION

posEye Construction Engine

The core reconstruction container executes Structure-from-Motion (OpenSfM), dense multi-view stereo matching, Poisson mesh reconstruction, and texture projection. NVIDIA CUDA acceleration is leveraged automatically, with seamless CPU fallback on non-NVIDIA systems.

CUDA GPU CPU Fallback Dense MVS Poisson Mesh
STAGE 10 / PHASE 3 : SPATIAL OUTPUTS

Deliverable Extraction & Zip-Slip Validation

The deliverable archive is extracted safely into the job workspace. A defensive Zip-Slip security filter validates canonical destination paths to prevent directory traversal vulnerabilities before handing files to the mesh converter.

Zip-Slip Guard Path Traversal Def Output Validation
STAGE 11 / PHASE 3 : SPATIAL OUTPUTS

Origin-Centered GLB Conversion & Delivery

Trimesh and pygltflib normalize large real-world UTM coordinates into origin-centered coordinates (preventing 32-bit floating point WebGL vertex jitter), convert raw OBJ/MTL into Draco-compressed GLB, and register raw LAZ point clouds and GeoTIFF orthophoto deliverables.

Draco GLB Origin Centering LAZ Point Cloud GeoTIFF Orthophoto
