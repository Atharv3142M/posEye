## 1. Defect Root Causes & Implementation Details

### Defect 1: 3D Viewer GLB Loading Failure (P0)
- **Root Cause A (CORS Origin Rejection):** Packaged Electron `loadFile()` serves pages from origin `file://` or `null`. FastAPI `CORSMiddleware` in `apps/orchestrator/src/orchestrator/main.py` explicitly allowed only `http://localhost:5173` and `http://localhost:3001`. Starlette rejected requests from the Electron browser window with a CORS violation.
  - *Fix:* Configured `CORSMiddleware` with `allow_origins=["*"]`, `allow_credentials=False`, and added explicit CORS headers to `/jobs/{id}/assets/{asset}`.
- **Root Cause B (Async Token Race Condition):** `apiBaseSync()` and `apiTokenSync()` in `apps/desktop/src/renderer/api.ts` returned empty strings until the async promise `apiBase()` resolved. Three.js `GLTFLoader` triggered synchronously on mount, sending requests without auth tokens and receiving HTTP 401 Unauthorized.
  - *Fix:* Added synchronous IPC bridge `envSync` via `ipcRenderer.sendSync("env:sync")` in `preload.cjs`, initializing `cachedBase` and `cachedToken` on the very first evaluation tick.
- **Root Cause C (Export Link WebContents Navigation):** Clicking `<a download>` on large assets like GeoTIFF and LAZ caused Electron's Chromium runtime to navigate or blank out the webContents.
  - *Fix:* Converted export triggers to programmatic anchor downloads and attached `will-download`, `will-navigate`, and `setWindowOpenHandler` listeners to `mainWindow.webContents` in `main.cjs`.

### Defect 2: Inaccurate NVIDIA GPU Detection (P0)
- **Root Cause:** Detection in `apps/orchestrator/src/orchestrator/system.py` called `subprocess.run(["nvidia-smi", ...])` directly. On many Windows installations, `nvidia-smi.exe` is located in `C:\Windows\System32\` or `C:\Program Files\NVIDIA Corporation\NVSMI\` rather than user `PATH`, causing a `FileNotFoundError`.
  - *Fix:* Added `_find_nvidia_smi()` probing PATH and standard system installation directories. Expanded the system status contract to include granular keys: `gpuHardware`, `nvidiaDriver`, `nvidiaSmi`, `dockerGpuAccess`, `engineGpuCapability`, and `gpuProcessingActive`.

### Defect 3: Dashboard Startup Latency (P1)
- **Root Cause:** `createWindow()` in `apps/desktop/electron/main.cjs` was invoked at the end of a long synchronous waterfall (virtualization check, Docker check, NodeODM container start waiting up to 90s, and blocking dialog boxes).
  - *Fix:* Moved `createWindow()` immediately after `app.whenReady()`. Docker Desktop detection, auto-start, and container health checks now run in an asynchronous background function `initializeServices()`, streaming real-time status (`app-status`) to the Dashboard without freezing window presentation.

### Defect 4: OpenDroneMap 1970 Epoch & Missing GeoRef in Report
- **Root Cause:** Frame extraction in `extract.py` only injected GPS coordinates, omitting EXIF `DateTimeOriginal`, `DateTime`, `DateTimeDigitized`, and `GPSVersionID`. OpenSfM/ExifTool defaulted capture timestamps to `01/01/1970 00:00:00`.
  - *Fix:* Injected `DateTimeOriginal`, `DateTime`, `DateTimeDigitized`, `GPSDateStamp`, `GPSTimeStamp`, and standard `GPSVersionID = (2, 3, 0, 0)` into each extracted JPEG frame based on video start time and frame timestamp offset.

### Defect 5: UI Monochrome Overhaul & Windows Identity
- **Branding & Icon:** Replaced squashed 256x256 banner icon with a square emblem containing all 7 Windows icon resolutions (16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256). Added `app.setAppUserModelId("org.icarus.poseye")` on Windows.
- **Monochrome Design System:** Restyled `globals.css` and `components.css` to a high-contrast dark graphite palette (`#0d1117`, `#161b22`, `#21262d`, `#f0f6fc`). Replaced rainbow badges and decorative emojis with crisp technical typography.
